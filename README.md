# Англо-французький словник

Консольний застосунок на Python 3: зберігає слова англійською та їх переклад французькою.

## Можливості

- додати слово та переклад
- видалити слово
- знайти слово (за точним збігом, часткою слова або перекладом)
- змінити слово та/або переклад
- показати всі слова
- дані зберігаються у файлі `dictionary.json` і не втрачаються між запусками

## Запуск

```bash
python main.py
```

Потрібен лише Python 3.8+, сторонні бібліотеки не потрібні. Якщо `dictionary.json` ще немає, словник заповнюється кількома початковими словами (hello, cat, dog…).

## Приклад

```
=== Англо-французький словник ===
1. Додати слово
2. Видалити слово
3. Знайти слово
4. Змінити слово
5. Показати всі слова
0. Вихід
```
